# PANTHEON Landing Page

This repository hosts the official landing page and support/tribute portal for **PANTHEON**, a distraction-free, 100% offline, and ad-free workout tracking application.

The live page is deployed at [pantheonworkout.app](https://pantheonworkout.app/).

---

## 🏛️ Project Structure

This is a clean, static front-end repository optimized for high-performance and lightweight hosting on GitHub Pages:

*   **[index.html](file:///home/falat/Repositories/pantheon-page/index.html)**: The main landing page, featuring a detailed feature showcase, Google Play Store redirect with automatic language localization, and a high-fidelity interactive phone mockup of the app.
*   **[tribute.html](file:///home/falat/Repositories/pantheon-page/tribute.html)**: The tribute/donation page that allows users to support the developer off-app (complying with app store guidelines) using Pix, Ko-fi, or Buy Me A Coffee.
*   **[CNAME](file:///home/falat/Repositories/pantheon-page/CNAME)**: Configuration file mapping the GitHub Pages site to the custom domain `pantheonworkout.app`.
*   **Assets**: Minimalist design system assets (SVG logo, multi-resolution app icons, and favicons).

---

## ✨ Features

*   **Dual-Language Interface**: Integrated Portuguese (PT) and English (EN) translation toggle.
*   **Modern Aesthetics**: Ultra-clean monochrome/dark-mode visual design with smooth hover effects, micro-animations, and glow backdrops.
*   **Interactive Showcases**: CSS-based interactive phone screen simulations allowing visitors to preview the training calendar, workout log, history, and settings within the landing page.
*   **PWA Ready**: Complete set of standard icons and web manifest targets for progressive loading.

---

## 🚀 Deployment

The site is served directly using **GitHub Pages** using a custom domain.

To publish updates:
1. Make changes to the HTML/CSS or assets locally.
2. Commit the changes to the `master` branch.
3. Push to GitHub, and the site will be automatically built and redeployed.
